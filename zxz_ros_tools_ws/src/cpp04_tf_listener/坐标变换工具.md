# 坐标变换工具  
`tf2_ros`包中提供的常用节点如下：
- `static_transform_publisher`：该节点用于广播静态坐标变换
- `tf2_monitor`：该节点用于打印所有或特定坐标系的发布频率与网络延迟
- `tf2_echo`：该节点用于打印特定坐标系的平移旋转关系

`tf2_tools`包中提供的节点如下：
- `view_frames`：该节点可以生成显示坐标系关系的pdf文件，该文件包含树形结构的坐标系图谱

1. 启动乌龟动态坐标变换节点
```bash
$ ros2 launch cpp03_tf_broadcaster demo03_launch.py
```

2. 查看turtle1相对于world坐标系的发布频率及网络延迟
```bash
$ ros2 run tf2_ros tf2_monitor turtle1 world
```
